# Data Structures 
This repository contains my programming assignments for Data Structures. Each assignment is organized into its own folder, containing the relevant source code.

# Assignments
Stacks — Java implementation of a pancake stack using a linked list, with push and pop operations to add and remove pancakes following the LIFO (Last In, First Out) principle.

Sorting — Java sorting algorithms project implementing Insertion Sort to rank Mario Kart racers by average lap time and Merge Sort to rank Mario Party players by stars and coins.

Queues — This assignment contains Java programming exercises focused on working with input, output, and basic program logic.

Matrix — Implements a social network in Java using an adjacency matrix to manage user profiles, track friendships, search for friends, and retrieve all friends of a profile.

Linear Probing - Java-based Minecraft inventory system using a linear-probing hash table to add, search, update, and delete items, with automatic resizing and rehashing to manage collisions efficiently.

Hash Tables - Java-based crime database that uses hash tables with separate chaining and linked lists to store, search, delete, and analyze Rutgers crime incidents, including location rankings and crime category breakdowns.

Binary Search Trees - Java implementation of a binary search tree (BST) to manage flowers by heat signature, featuring insertion, duplicate prevention, and Hibbard deletion to remove nodes while maintaining BST properties.

# Languages and Tools
java, PowerShell, VS Code
